## 測試實作細節

### 測試設置

使用 Vitest 的 fake timer 功能固定測試時間：

```javascript
beforeEach(() => {
  // 固定當前時間為 2026-01-06 12:00:00
  vi.useFakeTimers()
  vi.setSystemTime(new Date('2026-01-06T12:00:00'))
})

afterEach(() => {
  vi.useRealTimers()
})
```

### 測試結構

測試檔案採用分類結構組織：

```
describe('formatRelativeTime')
├── describe('無效輸入')
│   ├── it('應處理 null 值')
│   ├── it('應處理 undefined')
│   └── it('應處理空字串')
├── describe('時間格式化')
│   ├── it('應顯示「剛剛」於 1 分鐘內')
│   ├── it('應顯示分鐘數')
│   ├── it('應顯示小時數')
│   ├── it('應顯示天數')
│   ├── it('應顯示月份數')
│   └── it('應顯示年數')
├── describe('未來時間')
│   └── it('應顯示「剛剛」於未來時間')
└── describe('輸入格式')
    ├── it('應接受 Date 物件')
    ├── it('應接受 ISO 8601 字串')
    └── it('應接受時間戳字串')
```

