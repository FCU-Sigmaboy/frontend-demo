## 投影片 6: 測試設計方法 (2 分鐘)

3. **狀態轉換測試** - 交易狀態流程
4. **錯誤處理測試** - 網路錯誤、授權錯誤

describe('評分邊界值測試', () => {

  it('評分 5 應該被接受 (最大有效值)')

## Demo 流程 (穿插於簡報中)

1. **執行測試** (30 秒)
   ```bash
   npm run test
   ```

2. **產生覆蓋率報告** (30 秒)
   ```bash
   npm run test:coverage:html
   ```

3. **展示報告** (1 分鐘)
   - 開啟 coverage/index.html
   - 開啟 reports/eslint-report.html
   - 開啟 reports/code-metrics.html
