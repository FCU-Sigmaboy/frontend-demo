04 錯誤處理測試

4.1 ~ 4.4 常見錯誤模擬

System Wide
  • 🔴 認證錯誤: 未登入呼叫保護 API
  • 🔴 資料庫錯誤: RPC 呼叫失敗或連線中斷
  • 🔴 網路異常: 模擬 fetch 拋出網路錯誤
  • 🔴 權限拒絕: 地理位置權限被拒
