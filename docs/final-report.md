# 軟體測試專題成果報告

## 一、執行摘要

本文件為 FCU Sigmaboy 物品交換平台前端應用程式的軟體測試專題成果報告。本專案使用 JavaScript/Vue.js 技術架構，採用 Vitest 作為測試框架，等同於 Java 專案中的 JUnit。

**測試重點：以 `src/api` 為核心測試目標**，針對網站重要功能的 API 層進行完整測試。

## 三、功能說明

### 3.1 八大核心功能

1. **用戶認證系統** - 登入、登出、個人資料管理
2. **物品刊登管理** - 建立、編輯、刪除、搜尋物品
3. **交易管理系統** - 發起、確認、取消、追蹤交易
4. **即時訊息系統** - 對話管理、即時訊息

6. **評價系統** - 交易評價與評分
7. **地圖搜尋功能** - 地圖定位、附近搜尋
8. **追蹤與收藏** - 追蹤用戶、收藏物品

## 五、測試設計

### 5.1 測試設計方法

1. **等價類別劃分 (Equivalence Partitioning)**
   - 將輸入分為有效和無效等價類別
   - 範例：評分驗證 (1-5 有效，其他無效)

2. **邊界值分析 (Boundary Value Analysis)**
   - 測試邊界值和鄰近值
   - 範例：評分 0, 1, 5, 6

3. **狀態轉換測試 (State Transition Testing)**
   - 測試狀態變化的正確性
   - 範例：交易狀態流程

4. **錯誤處理測試**
   - 網路錯誤、授權錯誤等

### 5.2 測試分類

| 類別 | 測試數量 | 說明 |
|------|----------|------|

## 九、執行指令

```bash
# 安裝相依套件
npm install

# 執行所有測試
npm run test

# 執行測試並產生覆蓋率報告
npm run test:coverage

# 產生 ESLint 程式碼審查報告
npm run lint:report
npm run lint:html

# 產生程式碼度量報告
npm run metrics

# 產生所有報告
npm run report:all
```
